## 🧠 Dev Gyaan & Golden Rules (ज्ञान की बातें)

1. **Consistency > Motivation**  
   Har roz chahe 30 minute hi code karo, lekin break mat lo. Motivation aayegi aur jayegi, lekin consistency hi skills build karegi.

2. **Understand the "Why" behind the "How"**  
   Sirf `==` aur `===` ka syntax mat rato, Type Coercion ka rule samjho. Execution Context aur Call Stack hi JavaScript ka asli dimaag hain.

3. **Errors are Proof That You're Trying**  
   Jab `TypeError: undefined is not a function` ya `ReferenceError` aaye, ghabrana mat—console aur debugger tumhare sabse acche dost hain. Real learning tabhi shuru hoti hai jab code crash karta hai.

4. **KISS Principle (Keep It Simple, Stupid)**  
   Over-engineering se bacho. Readable aur clean code hamesha fancy "one-liner" code se behtar hota hai. Jo code 6 mahine baad tumhe khud samajh na aaye, wo bekar hai.

5. **Practice > Passive Watching**  
   Sirf tutorials dekh kar koi developer nahi banta. Jab tak haath se code nahi likhoge aur bugs fix nahi karoge, tab tak concept pakka nahi hoga.
